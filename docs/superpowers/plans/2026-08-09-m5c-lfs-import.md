# M5c Git LFS 迁入桥 实现计划

**Goal:** 兑现 M5 的另一条头条验收——**既有 LFS 仓库一键迁入**（spec §12.3、§8）。

**Architecture:** 迁入是**一次性的、有审计的、可中断的**批处理。它的安全纪律与
`arca gc` 同级：**在把指针文件换成真实内容之前，必须先证明那份内容就是指针
声称的那一份**。校验不过就停下，绝不覆盖——指针是找回内容的唯一线索。

**Tech Stack:** Rust 2021 / MSRV 1.85 · `sha2`（arca-cli 已依赖）

---

## 为什么这块的风险在「覆盖」而不在「解析」

LFS 指针只有三行，解析不会出错。真正会出事的是第二步：**用一份字节覆盖掉
指针文件**。如果那份字节不是指针声称的那一份（对象缺失、被截断、被换过），
覆盖之后：

- 指针没了 —— `oid` 是找回原内容的唯一线索，它就在被覆盖的那几行里；
- 内容是错的 —— 而且看起来是「迁移成功」。

所以本切片的核心纪律：**先校验 SHA-256 等于 `oid`，再写；写用 tmp → rename；
任何一步不确定就跳过这个文件并记进审计报告，绝不中止整批**（一个对象缺失
不该让另外 999 个迁不进来）。

## Global Constraints

- MSRV **1.85**。**每个任务自己跑完四项门禁再交**。
- `#![forbid(unsafe_code)]`。**`arca-core` 一行不改**。
- 只在 `main` 分支。提交信息、文档、注释一律中文。
- **I3**：迁入不得销毁任何东西。指针文件被替换是「原地改写」，
  而它的前提是内容已经过校验且已落盘。
- **绝不调用 `git lfs`**：迁入要在**没装 git-lfs 的机器上**也能跑——
  对象就在 `.git/lfs/objects/` 里，布局是固定的。依赖外部二进制会让
  「一键迁入」变成「先装 git-lfs」。

---

### Task 1: 指针解析（严格，宁可不认也不猜）

- [ ] `LfsPointer::parse(text) -> Option<LfsPointer>`：按 LFS spec 严格解析
      （`version https://git-lfs.github.com/spec/v1` + `oid sha256:<64 hex>` + `size <n>`）。
- [ ] **不是指针就返回 `None`**，不是错误——绝大多数文件本来就不是指针。
- [ ] 体积上限：超过几 KB 的文件直接不当指针看（真指针只有百来字节），
      免得把一个大文本文件整个读进来做正则。

### Task 2: 对象定位与校验

- [ ] `.git/lfs/objects/<前两位>/<接着两位>/<完整 oid>` —— 布局固定，不调 `git lfs`。
- [ ] **算 SHA-256 并与 `oid` 比对**。不等 → 这个文件**跳过**并记进报告，
      绝不覆盖。
- [ ] `size` 也要对上——`size` 对不上而哈希对得上是不可能的，
      两者都验是为了让**指针本身损坏**这种情况也能被认出来。

### Task 3: 就地替换与审计报告

- [ ] tmp → rename，与全项目其它写入同一纪律。
- [ ] 审计报告逐文件给结论：`已迁入` / `跳过（原因）`。spec §8：
      「逐文件用厂商提供的校验和验证完整性，**出具迁移审计报告**」。
- [ ] `--dry-run` 是**默认**（与 `arca gc` 同一纪律）：先让人看清单。
- [ ] 退出码：有任何文件被跳过 → 非 0。「一半迁成功了」不该看起来像全成功。

### Task 4: 命令壳与端到端

- [ ] `arca import lfs <路径> [--yes]`。
- [ ] 端到端：手工造一个带 LFS 指针与对象的仓库（**不需要装 git-lfs**），
      跑迁入，断言文件内容逐字节正确、指针不复存在。
- [ ] **反面**：对象缺失 / 哈希不符 / 指针损坏，各自断言「指针文件原封不动」。

## Self-Review

**最容易写错的**是「校验失败之后还是写了」。这类代码很容易写成
「先打开目标文件准备写，再校验」——那样一个 `truncate` 就已经把指针毁了。
纪律是：**校验通过之前，目标文件的字节一个都不能动。**

**范围**：LFS Batch API（让 arcad 冒充 LFS 服务端）属 v2，本切片只做**迁入**。
spec §8 明说「LFS 桥仅用于既有 LFS 仓库迁入」。
